Mugunthan Rajamani Mechanical Design Portfolio

This static website is intended for the existing mugunthan-portfolio. GitHub Pages repository.

Connector development at Teraxis is featured first, in this order:
1. ARINC 801: 2, 4, 6, 8 and 12-channel plugs and receptacles.
2. MPO: 1, 2, 3, 4, 6 and 8-channel plugs and receptacles.
3. Expanded beam: modelled only; not yet manufactured; future project.
4. Ruggedized optical: 4-channel plug, square-flange and jamnut receptacles.
5. Optical termini: current development project.

All connector development is identified as part-time Teraxis work carried out during evenings and weekends. No Teraxis start date has been added.

The original nine mechanical case studies follow the connector projects.
The website includes the updated resume in PDF and editable Word formats.
CAD images can be enlarged; the ARINC 801 and MPO walkthroughs use standard video controls.

To publish manually, extract this archive and upload its contents to the root of the existing repository, keeping the assets folder structure. Commit the changes to the existing GitHub Pages publishing branch. No build step is required.
